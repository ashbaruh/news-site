# פינת המלחמות — המסלול מהבינה הפרטית לאתר

## בשורה אחת

המק מריץ את הבינה ומניח **קובץ אחד לכל זירה** בתיבה. הקובץ נבדק מול חוזה קפדני, הופך ל**טיוטה**, ומתפרסם **רק אחרי שאתה מאשר**.

```
  המק (בינה פרטית)
      │  קובץ JSON — בכיוון אחד בלבד
      ▼
  data/war/inbox/            ← תיבה
      │  tools/war_contract.py בודק
      ├─ נכשל → data/war/rejected/   (רשימת שגיאות)
      └─ עבר  → data/war/drafts/<זירה>/   (טיוטה + תצוגה מקדימה של רמות האימות)
                    │  אתה מוסיף את שם הטיוטה ל-data/war/approved.json
                    ▼
            data/war/published.js    ← מה שהאתר מציג
```

## מה החוזה אוכף (ולמה)

| כלל | למה |
|---|---|
| **אין לבינה שדה "מאומת"** — אם היא שולחת כזה, הקובץ נדחה | רמת האימות מחושבת מ-`source_root_id`. בינה לא יכולה "להחליט" שמשהו מאומת |
| **כל מקור חייב להיות רשום מראש** ב-`data/sources.js`, עם רישיון | הבינה לא ממציאה מקורות. מקור חדש = אדם מוסיף אותו קודם (רישוי מרגע החיבור — מהמפרט) |
| **"מה לא מאומת" חובה** — לכל אירוע, וגם סעיף נפרד | סעיף 4 במפרט |
| **חזיתות/צירים בשם** — לפחות אחד | סעיף 3: לא "הלחימה נמשכת" |
| **חלון זמן מוגדר**, עד 72 שעות, ולכל אירוע "חדש בחלון" כן/לא | סעיף 1: מה חדש ומה אימות מאוחר |
| **מטרות אסטרטגיות בשלוש רשימות נפרדות**: מוצהרת / מוסקת / תחזית | סעיף 7: לא לערבב כעובדה אחת |
| **המפה תמיד הערכה** (`is_assessment: true`) + רמת ביטחון | "הערכה אנליטית, לא קו שליטה מאומת" |
| **מגמות כלכליות עם מספרים** ומקור | סעיף 6 |
| **ציטוט מקורות + תאריך**, וכל מקור מהדיווחים חייב להופיע שם | סעיף 8 |
| **הורדת סטטוס חייבת "מאיפה לאן"** | כדי שהקורא יראה שהאתר תיקן את עצמו |
| **בלי HTML, בלי קישורים שאינם https, בלי שדות לא מוכרים**, עד 300KB | גבול האבטחה: "השרת בודק את מבנה הקלט" |

## מה נבדק (27 בדיקות — `python tools/test_war_contract.py`)

קובץ תקין עובר · שדה "verified" מהבינה נדחה · מקור מומצא נדחה · אירוע בלי מקור נדחה · HTML נדחה · `javascript:` נדחה · מפה "ודאית" נדחתה · מטרות מעורבבות נדחו · חלון של 100 שעות נדחה · תאריך עתידי נדחה · זירה `../../index` נדחתה · ועוד.

**בדיקה מקצה לקצה (16/09/2026):** קובץ תקין → טיוטה עם תצוגה "1 מאומת, 1 מקור-שורש משותף". קובץ זדוני → נדחה. קובץ טקסט → נדחה. לפני אישור — לא פורסם כלום. אחרי אישור — פורסם. ניסיון להכניס `../../index.html` לרשימת האישורים — נחסם. **טיוטה שנערכה אחרי אישור — ירדה מהפרסום אוטומטית.**

## איך מאשרים

פותחים את `data/war/approved.json` ומוסיפים את שם הטיוטה:
```json
{
 "approved": ["drafts/iran/2026-09-17T0600__run-042.json"]
}
```
בכל זירה מוצגת **הטיוטה המאושרת האחרונה**. טיוטות ישנות נשארות — היסטוריה מלאה.
